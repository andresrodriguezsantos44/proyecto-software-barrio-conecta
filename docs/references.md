# Referencias Bibliográficas

Este documento lista las fuentes y estándares que sustentan el diseño y la implementación de BarrioConecta.

## Bibliografía Técnica
1.  **Agile Manifesto** (2001). *Manifesto for Agile Software Development*. [Agile Alliance](https://agilemanifesto.org).
2.  **CEPAL** (2022). *Perspectivas del comercio internacional de América Latina y el Caribe 2022*. [Naciones Unidas](https://repositorio.cepal.org).
3.  **Fielding, R. T.** (2000). *Architectural styles and the design of network-based software architectures*. [Tesis doctoral, UC Irvine](https://roy.gbiv.com/pubs/dissertation/top.htm).
4.  **Fowler, M.** (2018). *Refactoring: Improving the design of existing code*. Addison-Wesley.
5.  **MongoDB Documentation** (2023). *Geospatial Queries*. [Manual de MongoDB](https://www.mongodb.com/docs/manual/geospatial-queries/).
6.  **Pressman, R. S., & Maxim, B. R.** (2021). *Software Engineering: A Practitioner's Approach*. McGraw-Hill.
7.  **Scrum Guide** (2020). *The Definitive Guide to Scrum: The Rules of the Game*. [Scrum.org](https://scrumguides.org).
8.  **Vue.js Documentation** (2023). *The Progressive JavaScript Framework*. [Vuejs.org](https://vuejs.org).

## Estándares del Proyecto
- **RFC 2119**: Key words for use in RFCs to Indicate Requirement Levels (MUST, SHOULD, MAY).
- **Gherkin**: Domain-specific language for behavior-driven development (Given/When/Then).
- **SemVer**: Semantic Versioning 2.0.0.
